# 围棋学堂 · 新手教程（Go / Weiqi Tutorial）

一个带**新手教程**的围棋小游戏，使用纯 HTML + CSS + JavaScript（无任何构建依赖），
打开浏览器即可游玩。玩家通过一步步完成互动任务，从零学会围棋。

剧情与世界观设定见 [STORY-BIBLE.md](STORY-BIBLE.md)。

## 🎮 功能

- **行动课程（17 课）**：每课固定采用“动作示范 → 两道局部题 → 短对局 → 简短复盘”
  - 第一阶段：轮流落子
  - 第二阶段：堵气与被打吃状态、提子、逃跑、连接、切断、禁入点
  - 第三阶段：真眼、两眼活棋、打劫、围地
  - 第四阶段：双叫吃、征子、枷吃、对杀
  - 第五阶段：开局方向与 9 路毕业对局
- **局部短对局**：对手会按题目回应两三手；错误落子自动撤回，可立即重试
- **🎓 毕业对局**：完成全部行动课后，独立下完一局 9 路实战并数地验收
- **自由对局**：
  - 🤖 人机对弈（简单 AI，你执黑）
  - 👥 双人对弈（本地双人轮流落子）
  - 悔棋、放弃一手、新局、数地（贴目 7.5）
- **入门围棋规则引擎**：气、提子、禁入点（自杀）、单劫（Ko）、简化面积数地
- **进度保存**：课程完成情况保存在浏览器 localStorage 中

## 🚀 运行方式

直接用浏览器打开 `index.html` 即可（无需安装任何依赖）：

```
E:\Work\Weiqi\index.html
```

也可以用 VS Code 的 Live Server 扩展，或在项目目录启动一个静态服务器：

```bash
# Python
python -m http.server 8080
# Node
npx serve .
```

然后访问 `http://localhost:8080`。

## 🧩 设计说明

- **棋盘**：9 路（9×9），坐标采用字母 + 数字（棋盘左侧数字、底部字母）。
- **规则引擎**（`go-core.js`）：
  - `isLegal(color, i)` 判断落子合法性，自动处理提子、禁入点与打劫。
  - 打劫采用经典"劫点"实现：上一手提掉单子后，禁止对方在该点立刻提回单子。
  - `territory()` 采用"盘上活子 + 围住空点"的简化面积数地法。程序不会自动判断死子，结算前需先把死子提净。
- **教程引擎**（`main.js`）：支持演示、选择、落子、局部短对局、错误自动撤回和完整对局。
- **AI**：贪心策略——优先提子 → 逃命（被征死则果断弃子）→ 贴近对方 → 随机，适合新手练习。

## 🎯 玩法提示

1. 从“📖 新手教程”开始，按顺序完成 17 课；每课完成短对局和复盘后解锁下一课。
2. 落子任务中，点错会有红圈或提示，程序会拦截非法落子（禁入点/打劫）。
3. 学完后到"🎮 自由对局"挑战电脑，或和朋友双人对弈，最后用"数地"判定胜负。
