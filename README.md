# 围棋学堂 · 新手教程（Go / Weiqi Tutorial）

一个带**新手教程**的围棋小游戏，使用纯 HTML + CSS + JavaScript（无任何构建依赖），
打开浏览器即可游玩。玩家通过一步步完成互动任务，从零学会围棋。

## 🚀 运行方式

直接用浏览器打开 `index.html` 即可（无需安装任何依赖）：

```
E:\Work\Weiqi\index.html
```

也可以用 VS Code 的 Live Server 扩展，或在项目目录启动一个静态服务器：

```bash
# Python
python -m http.server 8080
# Node
npx serve .
```

然后访问 `http://localhost:8080`。

## 🧩 设计说明

- **棋盘**：9 路（9×9），坐标采用字母 + 数字（棋盘左侧数字、底部字母）。
- **规则引擎**（`go-core.js`）：
  - `isLegal(color, i)` 判断落子合法性，自动处理提子、禁入点与打劫。
  - 打劫采用经典"劫点"实现：上一手提掉单子后，禁止对方在该点立刻提回单子。
  - `territory()` 采用"棋子 + 围住空点"的简易数地法。
- **教程引擎**（`main.js`）：支持 `text`（讲解）、`visual`（高亮演示）、`demo`（动画演示）、`quiz`（选择）、`move`（落子）、`free`（对局）六种步骤类型，`lessons.js` 中以数据形式声明，方便扩充。
- **AI**：贪心策略——优先提子 → 逃命 → 贴近对方 → 随机，适合新手练习。

## 🎯 玩法提示

1. 从"📖 新手教程"开始，按顺序完成 20 课，每课做对后会自动解锁下一课。
2. 落子任务中，点错会有红圈或提示，程序会拦截非法落子（禁入点/打劫）。
3. 学完后到"🎮 自由对局"挑战电脑，或和朋友双人对弈，最后用"数地"判定胜负。
